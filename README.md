# Daily Planer — аддон для World of Warcraft

Планировщик ежедневных активностей в виде заметок с вкладками и чекбоксами.

## Возможности (v1.1.0.1)

- Несколько вкладок-заметок (переключение кликом)
- Добавление своих активностей с галочками выполнения
- **Квесты** — добавление по ID, ссылке из чата или поиску по названию
- Автоматическая отметка выполненных квестов через API игры
- Клик по квесту: открыть в журнале (если взят) или метка на карте (если нет)
- Переименование и удаление вкладок
- Сохранение данных между сессиями
- Перемещаемое окно

## Установка

1. Скопируйте папку `DailyPlaner` в каталог аддонов WoW:
   ```
   World of Warcraft\_retail_\Interface\AddOns\DailyPlaner
   ```
2. Перезапустите игру или введите `/reload`.
3. Включите аддон в меню «Модификации» при необходимости.

## Использование

| Команда | Действие |
|---------|----------|
| `/dp` | Открыть / закрыть окно |
| `/dplan` | То же самое (если `/dp` занят другим аддоном) |
| `/dailyplaner` | То же самое |
| `/dp reset` | Сбросить все данные |

Если команды не работают, включите вывод ошибок в чате: `/console scriptErrors 1`, затем `/reload`.

### Интерфейс

- **Вкладки** — клик по названию для переключения, **+** для новой заметки
- **Карандаш** на вкладке — переименовать, **крестик** — удалить
- **Стрелки / колёсико мыши** над вкладками — прокрутка, если вкладок много
- **Чекбокс** — отметить выполненным (у квестов синхронизируется с игрой)
- **Клик по названию квеста** — журнал или метка на карте
- **Крестик справа** — удалить пункт
- **Квест** — добавить дейлик/квест (ID, ссылка Shift+клик из чата, или поиск по имени)
- Поле внизу — обычная активность (Enter или «Добавить»)

### Квесты: ID или название?

В данных сохраняется **quest ID** (стабильный идентификатор). В интерфейсе показывается **название** из API игры.

Поиск по названию ищет среди квестов в журнале и на карте текущей зоны. Для редких дейликов удобнее вставить **ссылку на квест из чата** (Shift+клик) или указать **числовой ID**.


## Дальнейшие идеи

- Сброс чекбоксов по расписанию (ежедневно в определённое время)
- Готовые шаблоны (дейлики, рейд, PvP)
- Отслеживание прогресса WoW API (квесты, локи)
- Миникнопка на панели
- Синхронизация между персонажами

## Разработка

После изменения `.lua` файлов скопируйте папку `DailyPlaner` в каталог AddOns и выполните в игре `/reload`.

Номер интерфейса в `.toc` можно обновить командой в игре:
```
/run print((select(4, GetBuildInfo())))
```
